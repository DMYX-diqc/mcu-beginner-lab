# 03. 基于函数的秒值转时间值

> 目录：`03.function-based-seconds-to-time-experiment`

## 实验目的

通过本实验，掌握 C 语言中**函数**的定义与使用，理解模块化编程的思想：

1. 掌握函数的**声明**、**定义**与**调用**；
2. 理解函数**参数传递**与**返回值**；
3. 了解 `static` 关键字修饰函数的作用（限定作用域）。

## 实验内容

在「秒值转时间值」的基础上，把转换逻辑封装成一个函数 `CalcTimeVal`：

- 输入：秒值 `tick` 和转换类型 `type`（小时/分钟/秒）；
- 输出：对应的时间分量；
- 在 `main` 中调用该函数三次，分别得到小时、分钟、秒。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 函数 | 声明、定义、调用 |
| 参数与返回值 | 形式参数、实际参数、`return` 返回值 |
| `static` | 内部函数，限定作用域 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio（或任意支持 C 的 IDE / 编译器）

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 在 `Code/` 的源文件中补全实现；
3. 编译运行后，按提示输入一个 0~86399 之间的整数；
4. 观察换算结果。

## 预期结果

输入 `3661`，输出：

```
Current time: 01-01-01
```
