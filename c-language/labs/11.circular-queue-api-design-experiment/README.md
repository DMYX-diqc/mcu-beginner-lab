# 11. 循环队列 API 设计

> 目录：`11.circular-queue-api-design-experiment`

## 实验目的

通过本实验，掌握**循环队列**数据结构及其 API 设计：

1. 理解队列「先进先出（FIFO）」的特性；
2. 理解**循环队列**如何用固定大小的数组实现，避免搬移数据；
3. 掌握队列的基本操作：入队（Enqueue）、出队（Dequeue）、查询队列长度；
4. 体会把数据结构封装成可复用模块的方法。

## 实验内容

设计并实现一个 `Queue` 循环队列模块，用于存放任务节点，并对外提供入队、出队、获取队列长度等接口。

`DataType.h`（基本类型定义）已提供，你需要完成：

- 队列结构体与任务结构体的定义；
- 队列的初始化、入队、出队、查询等 API；
- `App` 中的调用验证。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 队列 | 先进先出（FIFO） |
| 循环队列 | 固定数组 + 头尾指针环形使用 |
| API 设计 | 数据结构封装为可复用模块 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 设计并实现 `Queue` 模块；
3. 在 `App` 中验证入队、出队、越界处理等行为正确。

## 预期结果

队列能够正确完成元素的入队与出队，且遵循先进先出顺序；队满、队空等边界情况处理正确。

2. 如何区分「队满」和「队空」两种状态？
