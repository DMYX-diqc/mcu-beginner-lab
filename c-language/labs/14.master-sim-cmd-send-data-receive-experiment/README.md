# 14. 模拟主机：发送命令、接收数据

> 目录：`14.master-sim-cmd-send-data-receive-experiment`

## 实验目的

通过本实验，掌握**主机（Master）角色**的通信逻辑，与从机形成完整闭环：

1. 理解主机「**发送命令 → 接收数据 → 处理数据**」的工作流程；
2. 掌握如何复用协议模块（`PackUnpack`）下发命令、解析回传数据；
3. 掌握命令下发（`SendCmdToMCU`）与数据处理（`ProcMCUData`）的分层设计。

## 实验内容

模拟一个主机设备，向从机下发命令，并接收、解析从机回传的数据。

工程已提供：

- `DataType.h`：基本类型定义；
- `PackUnpack`：协议打包/解包模块（可直接使用）。

你需要完成：

- `SendCmdToMCU` 模块：把命令打包并发送给从机；
- `ProcMCUData` 模块：解析从机回传的数据；
- `App`：组织主机的整体收发流程。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 主机逻辑 | 发命令 → 收数据 → 处理 |
| 协议复用 | 调用 `PackUnpack` 接口收发 |
| 模块分层 | 命令下发与数据处理分离 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 补全 `SendCmdToMCU`、`ProcMCUData`、`App`；
3. 编译运行，模拟命令下发与数据接收处理。

## 预期结果

主机能够正确下发命令，接收并解析从机回传的数据。

## 思考与拓展

1. 主机和从机如何约定命令与数据的格式？
2. 如果主机发送命令后长时间收不到回复，应该怎么处理？
