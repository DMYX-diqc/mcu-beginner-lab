# 07. 基于结构体指针的秒值转时间值

> 目录：`07.struct-pointer-based-seconds-to-time-experiment`

## 实验目的

通过本实验，掌握**结构体指针**的使用：

1. 理解结构体指针与 `->` 成员访问运算符；
2. 掌握通过结构体指针作为函数参数，在函数内部修改外部结构体；
3. 体会「指针传参」相比「值传参」在效率和功能上的区别。

## 实验内容

在「结构体转时间值」的基础上，改用**结构体指针**传参：

1. 定义结构体 `StructTimeVal`（含 `hour`、`min`、`sec`）；
2. 函数 `CalcTimeVal` 接收结构体指针 `pTV`，通过 `pTV->hour` 等写入结果；
3. 函数返回有效标志，`main` 判断后再打印。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 结构体指针 | 指向结构体的指针 |
| `->` 运算符 | 通过指针访问结构体成员 |
| 指针传参 | 函数内修改外部结构体 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio（或任意支持 C 的 IDE / 编译器）

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 在 `Code/` 的源文件中补全实现；
3. 编译运行后，按提示输入一个整数；
4. 观察正常输入与越界输入的不同输出。

## 预期结果

输入 `3661`，输出：

```
Current time: 01-01-01
```

输入越界值（如 `90000`），输出错误提示。
