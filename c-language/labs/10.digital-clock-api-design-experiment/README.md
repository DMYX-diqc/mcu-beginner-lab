# 10. 电子钟 API 设计

> 目录：`10.digital-clock-api-design-experiment`

## 实验目的

通过本实验，掌握**模块 API 设计**的思想，把电子钟封装成一个独立模块：

1. 理解「**数据 + 接口**」分离的设计思路；
2. 学会设计一个模块的**对外接口**（头文件中的函数声明）；
3. 掌握用 `static` 变量把模块内部状态“隐藏”在模块内部。

## 实验内容

设计并实现一个 `RunClock` 电子钟模块，把时钟的运行逻辑（时/分/秒的推进、读写、显示）封装起来，对外只暴露一组清晰的 API。典型的接口包括：

- 初始化时钟；
- 设置 / 获取时间分量；
- 每个节拍（如每 2ms）推进一次时钟；
- 显示当前时间。

`DataType.h`（基本类型定义）已提供，你需要完成 `RunClock` 模块的头文件接口与 `.c` 实现，并编写 `App` 调用验证。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| API 设计 | 头文件接口声明 |
| 数据封装 | `static` 变量隐藏内部状态 |
| 模块化 | 模块内部实现与外部接口分离 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 设计并实现 `RunClock` 模块；
3. 在 `App` 中调用该模块验证时钟能正常设置、推进与显示。

## 预期结果

电子钟能从设定时间开始，按节拍正确推进，并能正确读取和显示当前时间。
