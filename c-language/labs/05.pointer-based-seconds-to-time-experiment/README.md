# 05. 基于指针的秒值转时间值

> 目录：`05.pointer-based-seconds-to-time-experiment`

## 实验目的

通过本实验，掌握 C 语言中**指针**的基本概念与使用：

1. 理解指针的本质——存放内存地址的变量；
2. 掌握指针作为**函数参数**，在函数内部修改外部变量；
3. 掌握指针的**算术运算**（`*(pTimeVal + N)`）访问数组元素；
4. 理解用「返回值 + 标志位」区分成功与失败的设计思路。

## 实验内容

在「秒值转时间值」的基础上，让函数通过**指针**把时、分、秒写回调用方：

1. 函数 `CalcTimeVal` 接收秒值和指针参数，通过指针写入三个时间分量；
2. 函数返回一个**有效标志**：输入越界时返回失败，调用方据此判断是否打印结果。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 指针 | 指针变量、取地址 `&`、解引用 `*` |
| 指针作参数 | 函数通过指针修改外部数据 |
| 指针算术 | `*(p + N)` 等价于 `p[N]` |
| 参数校验 | 输入合法性判断 |

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 在 `Code/` 的源文件中补全实现；
3. 编译运行后，按提示输入一个整数；
4. 观察正常输入与越界输入的不同输出。

## 预期结果

输入 `3661`，输出：

```
Current time: 01-01-01
```

输入越界值（如 `90000`），输出错误提示（例如 `Invalid tick value`）。
