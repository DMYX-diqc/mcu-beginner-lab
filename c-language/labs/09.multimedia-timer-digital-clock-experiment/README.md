# 09. 多媒体定时器电子钟

> 目录：`09.multimedia-timer-digital-clock-experiment`

## 实验目的

通过本实验，掌握 Windows **多媒体定时器**与**回调函数**，实现一个实时走动的电子钟：

1. 掌握 `timeSetEvent` 创建周期定时器；
2. 理解**回调函数**机制（定时到达时由系统调用指定函数）；
3. 掌握 `__stdcall` 调用约定与 `TIME_PERIODIC` 周期触发；
4. 理解「2ms 节拍 + 计数分频」得到 1 秒的周期调度思想。

## 实验内容

实现一个电子钟：定时器每 2ms 触发一次回调，程序累计 500 次（约 1 秒）后更新并显示一次时间。

工程已提供 `CalcHour`、`CalcMin`、`CalcSec` 三个计算模块（可直接使用），需要你补全：

- `Tick` 模块：维护秒值（`tick`）并提供自增、设置、读取接口；
- `CalcTime` 模块：汇总调用小时/分钟/秒计算，写回时间结构体；
- `App`：初始化、启动定时器、主循环，以及周期回调任务。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 多媒体定时器 | `timeSetEvent` 周期定时 |
| 回调函数 | 定时触发时被系统调用 |
| 调用约定 | `__stdcall` |
| 分频计数 | 2ms 计数 500 次 → 1s |
| 模块协作 | 多个 `.c` / `.h` 协同 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio
- 依赖：`winmm.lib`（工程已通过 `#pragma comment(lib, "winmm.lib")` 链接）

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 补全 `Tick`、`CalcTime`、`App` 三个模块；
3. 编译运行，观察控制台每秒打印一次时间。

## 预期结果

程序启动后，从设定的初始时间开始，控制台**每秒**打印一行当前时间，并持续递增。
