# 06. 基于结构体的秒值转时间值

> 目录：`06.struct-based-seconds-to-time-experiment`

## 实验目的

通过本实验，掌握 C 语言中**结构体**的定义与使用：

1. 掌握 `struct` 结构体的**定义**、**实例化**与**成员访问**；
2. 理解结构体把一组相关数据“打包”成一个整体；
3. 掌握用结构体变量作为函数参数（值传递）。

## 实验内容

在「秒值转时间值」的基础上，用**结构体**来表示时间：

1. 定义结构体 `StructTimeVal`，包含 `hour`、`min`、`sec` 三个成员；
2. 定义函数 `CalcTimeVal`，把换算结果写入结构体；
3. 在 `main` 中通过 `.` 运算符访问结构体成员并打印。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 结构体 | `struct` 定义与实例化 |
| 成员访问 | `.` 运算符 |
| 结构体作参数 | 结构体变量的传值 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio（或任意支持 C 的 IDE / 编译器）

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 在 `Code/` 的源文件中补全实现；
3. 编译运行后，按提示输入一个 0~86399 之间的整数；
4. 观察换算结果。

## 预期结果

输入 `3661`，输出：

```
Current time: 01-01-01
```
