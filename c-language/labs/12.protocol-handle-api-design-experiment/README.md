# 12. 协议处理 API 设计

> 目录：`12.protocol-handle-api-design-experiment`

## 实验目的

通过本实验，掌握**通信协议的分包与解包**处理，设计协议处理模块：

1. 理解通信中「数据包」的概念与格式约定；
2. 掌握**打包（Pack）**：把数据按协议格式组装成字节流；
3. 掌握**解包（Unpack）**：从字节流中解析出数据并校验；
4. 理解**校验和（Checksum）**用于检验数据完整性的作用。

## 实验内容

设计并实现一个 `PackUnpack` 协议处理模块。数据包由以下字段组成：

| 字段 | 说明 |
| --- | --- |
| 模块 ID | 标识数据来源/去向的模块 |
| 数据头 | 按位存放各数据字节的最高位 |
| 对象 ID | 标识具体操作或数据类型 |
| 数据 1~6 | 6 字节有效数据 |
| 校验和 | 用于校验数据包完整性 |

`DataType.h`（基本类型定义）已提供，你需要完成 `PackUnpack` 模块的打包、解包、校验接口及 `App` 验证。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 协议格式 | 数据包字段约定 |
| 打包 / 解包 | 数据 ↔ 字节流 |
| 校验和 | 完整性校验 |
| 位运算 | 按位存取数据头 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 设计并实现 `PackUnpack` 模块；
3. 在 `App` 中验证：打包后解包能得到原始数据，且校验和能识别错误数据包。

## 预期结果

数据打包后能正确解包还原；对完整数据包解包成功，对校验失败的数据包能正确识别。
