# 13. 模拟从机：接收命令、发送数据

> 目录：`13.slave-sim-cmd-receive-data-send-experiment`

## 实验目的

通过本实验，掌握**从机（Slave）角色**的通信逻辑，理解协议模块的实际应用：

1. 理解从机「**接收命令 → 处理命令 → 返回数据**」的工作流程；
2. 掌握如何复用已有的协议模块（`PackUnpack`）收发数据包；
3. 掌握命令解析（`ProcHostCmd`）与数据回传（`SendDataToHost`）的分层设计。

## 实验内容

模拟一个从机设备，接收主机下发的命令，解析后按需向主机回传数据。

工程已提供：

- `DataType.h`：基本类型定义；
- `PackUnpack`：协议打包/解包模块（可直接使用）。

你需要完成：

- `ProcHostCmd` 模块：解析主机命令并执行相应操作；
- `SendDataToHost` 模块：把数据打包并发送给主机；
- `App`：组织从机的整体收发流程。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 从机逻辑 | 收命令 → 处理 → 回数据 |
| 协议复用 | 调用 `PackUnpack` 接口收发 |
| 模块分层 | 命令解析与数据发送分离 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 补全 `ProcHostCmd`、`SendDataToHost`、`App`；
3. 编译运行，模拟主机命令的接收与数据回传。

## 预期结果

从机能够正确接收并解析命令，按命令要求组装数据包并回传给主机。

2. 命令解析如果遇到未知命令，应该怎么处理？
