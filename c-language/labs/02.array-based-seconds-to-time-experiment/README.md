# 02. 基于数组的秒值转时间值

> 目录：`02.array-based-seconds-to-time-experiment`

## 实验目的

通过本实验，掌握 C 语言中**数组**和**循环**的使用：

1. 掌握一维数组的**定义**、**初始化**与**下标访问**；
2. 掌握 `for` 循环的语法与遍历用法；
3. 理解「用数组 + 循环替代重复代码」的编程思想。

## 实验内容

在「秒值转时间值」的基础上，改用**数组**来存储时、分、秒三个分量：

1. 定义数组 `arrTimeVal[3]`，用下标分别存放小时、分钟、秒；
2. 用 `for` 循环遍历下标，计算并填充数组；
3. 按数组下标取出结果并打印。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 数组 | 一维数组的定义、下标访问 |
| 循环 | `for` 循环遍历 |
| 下标 | 用枚举常量作为数组下标 |

## 运行环境

- 操作系统：Windows
- 开发工具：Visual Studio（或任意支持 C 的 IDE / 编译器）

## 编译与运行

1. 用 Visual Studio 打开 `Project` 目录下的工程文件（`.sln`）；
2. 在 `Code/` 的源文件中补全实现；
3. 编译运行后，按提示输入一个 0~86399 之间的整数；
4. 观察换算结果。

## 预期结果

输入 `3661`，输出：

```
Current time: 01-01-01
```
