# 01. 输入秒值转时间值

> 目录：`01.seconds-to-time-conversion-experiment`

## 实验目的

这是 C 语言学习的第一课，通过一个最简单的小程序，掌握 C 程序的基本结构和输入输出：

1. 认识 C 程序的入口函数 `main`，理解程序从 `main` 开始执行；
2. 掌握 `printf` 的**格式化输出**（`%02d` 补零对齐）；
3. 掌握 `scanf_s` 从键盘**读取输入**；
4. 掌握整数除法 `/` 与取模 `%` 运算符，理解「秒 → 时:分:秒」的换算逻辑。

## 实验内容

编写程序，提示用户输入一个 0~86399 之间的秒值（`tick`），将其换算为“小时:分钟:秒”并打印。

换算关系：

- 小时：`tick / 3600`
- 分钟：`(tick % 3600) / 60`
- 秒：`(tick % 3600) % 60`
