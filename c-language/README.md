# C 语言程序设计

初阶第一站。通过「秒值—时间值转换」「电子钟设计」「通信协议」等 14 个实验，掌握 C 语言从变量、数组、函数、指针、结构体到多文件工程与 API 设计的完整语法与工程能力。

## 学习内容

| 阶段 | 知识点 | 实验 |
| --- | --- | --- |
| 基础语法 | 变量、输入输出、数组、函数、枚举 | 01–04 |
| 进阶 | 指针、结构体、结构体指针、多文件工程 | 05–08 |
| 应用 | 定时器、API 设计、循环队列、协议、主从机通信 | 09–14 |

## 怎么开始

1. 看 `assignments/chapter-tasks.md`，了解 14 个实验任务。
2. 用 Visual Studio 打开 `labs/` 下对应实验的 `.sln`。
3. 在 `Code/` 里补全代码，编译运行，验证结果。
4. 推荐书籍与教学视频见 `courseware/`。

## 目录结构

```text
c-language/
├── courseware/     # 推荐书籍、教学视频
├── labs/           # 实验任务框架（空工程，14 个）
└── assignments/    # 章节任务清单
```

## 开发环境

- Visual Studio（打开各实验 `Project/` 下的 `.sln`）。

> 参考答案在本仓库 `product/` 目录，建议先独立完成再对照。
