# mcu-beginner-lab · 嵌入式初阶培训

欢迎！这里是嵌入式初阶培训的学员资料库。按下面的顺序，从 C 语言基础一路学到 STM32 单片机开发。

## 学习路线

| 顺序 | 子项目 | 目录 | 学什么 |
| --- | --- | --- | --- |
| 1 | C 语言程序设计 | `c-language/` | C 语言语法与编程基础 |
| 2 | 51 单片机入门 | `mcu-51/` | 51 单片机外设编程 |
| 3 | 电路设计与制作 | `circuit-design/` | 原理图、PCB、焊接调试 |
| 4 | STM32 | `stm32/` | STM32F103 外设开发 |

## 目录结构

```text
.
├── c-language/       # C 语言程序设计
├── mcu-51/           # 51 单片机入门
├── circuit-design/   # 电路设计与制作
├── stm32/            # STM32
├── senior-works/     # 老学员作品（可跑通代码）
└── docs/             # 公共资料
```

每个子项目内部：

```text
<子项目>/
├── courseware/     # 课件、讲义、推荐书籍
├── labs/           # 实验任务框架（空工程，需要自己写代码）
├── assignments/    # 任务清单、大作业要求
├── hardware/       # 原理图、BOM、数据手册（硬件类）
└── tools/          # 开发工具下载与说明
```

## 快速开始

### 1. 下载仓库

点右上角绿色 **Code** 按钮 → **Download ZIP**，解压到本地。
（GitHub 网页只能浏览，不能直接运行工程，必须下载到本地。）

### 2. 装开发环境

| 模块 | 开发环境 |
| --- | --- |
| C 语言 | Visual Studio（勾选「使用 C++ 的桌面开发」） |
| 51 | Keil C51，见 `mcu-51/tools/` |
| STM32 | Keil MDK + STM32F1xx 器件包，见 `stm32/tools/` |

### 3. 打开工程写代码

| 模块 | 打开哪个文件 |
| --- | --- |
| C 语言 | 各实验 `Project/` 下的 `.sln` |
| 51 / STM32 | 各实验的 `.uvproj` / `.uvprojx` |

> 下载后第一次打开工程，先点一次「编译 / Build」，再开始写代码。

### 4. 按顺序学习

从 `c-language/` 开始，先看各子项目的 README，再打开 `labs/` 里的空工程完成实验。

---

> **参考答案**：完成实验后，在各子项目的 `product/` 目录查看参考答案。
