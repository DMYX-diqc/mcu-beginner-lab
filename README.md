# mcu-beginner-lab

嵌入式初阶培训统一资料库。面向培训部初阶学员，按「C 语言 → 51 单片机 → 电路设计与制作 → STM32」的顺序完成四个子项目，掌握从编程基础、单片机开发到硬件设计的完整入门能力。

## 四个子项目

| 子项目 | 目录 | 学员要完成 |
| --- | --- | --- |
| C 语言程序设计 | `c-language/` | 完成每章后面的编程任务 |
| 51 单片机入门 | `mcu-51/` | 完成每章任务 + 大作业 + PPT 汇报 |
| 电路设计与制作快速入门 | `circuit-design/` | 绘制 STM32 板子 + 焊接板子 |
| STM32 | `stm32/` | 完成每章任务 + 大作业 + PPT 汇报 |

## 目录结构

```text
.
├── docs/             # 公共资料（学习说明、跨项目文档）
├── c-language/       # C 语言程序设计
├── mcu-51/           # 51 单片机入门
├── circuit-design/   # 电路设计与制作快速入门
└── stm32/            # STM32
```

每个子项目内部统一结构（资料、任务、作业要求分开）：

```text
<子项目>/
├── README.md       # 本模块说明与学习目标
├── courseware/     # 课件、讲义、推荐书籍
├── labs/           # 任务框架（空工程，学生往里写代码；C / STM32）
├── assignments/    # 任务要求、大作业要求、验收标准
├── hardware/       # 原理图、BOM、数据手册（硬件类模块）
└── tools/          # 开发工具说明与下载链接
```

## 分支说明

| 分支 | 内容 | 面向谁 |
| --- | --- | --- |
| `main` | 课件、任务框架（空工程）、硬件资料、作业要求（不含完整代码） | 全体学员 |
| `solutions` | 参考答案（Product）+ 测试板子的完整例程 | 培训部干事 |

> 公开仓库中 `solutions` 分支对所有人可见，仅用于把答案与默认分支隔离，方便学员从默认分支下载不含答案的资料。若需要严格的访问控制（答案仅干事可见），请改用私有仓库或单独的私有仓库存放答案。

## 权限说明

- 仓库设为 **Public** 公开。
- 学员：无需分配权限，默认只读浏览、下载。
- 培训部干事：作为 **Collaborator** 添加，拥有编辑与推送权限。

## 快速开始

### 1. 获取仓库到本地

GitHub 网页只能浏览和下载，不能直接运行工程。先把仓库拿到本地：

- 学员：仓库页点绿色 **Code** → **Download ZIP** → 解压。
- 干事 / 进阶学员：`git clone <仓库地址>`。

### 2. 装好开发环境

- C 语言：Visual Studio（勾选「使用 C++ 的桌面开发」）。
- 51：Keil C51。
- STM32：Keil MDK + STM32F1xx DFP 器件包。
- 安装包不存放在仓库内，到各模块 `tools/README.md` 查看下载链接。

### 3. 打开工程

| 模块 | 打开哪个文件 |
| --- | --- |
| C 语言 | 各实验 `Project/` 下的 `.sln` |
| 51 | 各实验的 `.uvproj` |
| STM32 | 各实验的 `.uvproj` |

> 编译产物（`Objects/`、`Debug/`、`.o`、`.axf` 等）不在仓库内，下载后第一次打开工程请点一次「编译 / Build」。

### 4. 按顺序学习

先看各子项目 `README.md`，从 `c-language` 开始。任务起始框架在 `labs/`（空工程，需自己写代码）；参考答案（Product）和测试板子的完整例程在 `solutions` 分支。
