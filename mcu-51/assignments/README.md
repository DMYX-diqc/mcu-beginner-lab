# 51 单片机章节任务清单

> 目录：`assignments/`

本清单列出 51 单片机入门阶段需要依次完成的一系列实验任务。请按顺序完成，每完成一项在「完成」栏打勾（✅）。对应空工程模板在本仓库 `labs/` 目录下，参考答案在 `product/` 目录下。

## 任务清单

| 序号 | 任务名称 | 任务要求 | 涉及知识点 | 完成 |
| --- | --- | --- | --- | --- |
| 01 | LED 流水灯 | 点亮单个 LED，并实现流水灯效果 | GPIO 输出、`sbit` 位定义、软件延时 | ⬜ |
| 02 | 独立按键 | 按下按键点亮对应 LED，掌握按键消抖 | GPIO 输入、上拉电阻、消抖、`if` 判断 | ⬜ |
| 03 | 蜂鸣器 | 按键触发蜂鸣器发声，驱动原理 | 三极管驱动、GPIO 输出、有源/无源蜂鸣器 | ⬜ |
| 04 | 数码管 | 动态扫描显示数字，理解段码与位选 | 段码表、动态扫描、人眼视觉暂留 | ⬜ |
| 05 | 外部中断 | 用外部中断 0/1 响应按键事件 | `EX0/EX1`、`IT0/IT1`、中断服务函数 | ⬜ |
| 06 | 定时器 / 计数器 | 定时 1s 翻转 LED；计数 3 个脉冲翻转 LED | `TMOD`、`TH0/TL0` 初值、定时/计数模式 | ⬜ |
| 07 | PWM 与呼吸灯 | 改变占空比实现 LED 亮度渐变（呼吸） | PWM 周期与占空比、定时器模式 2 | ⬜ |
| 08 | 串口通信 | 通过串口向电脑发送字符串 | `SCON`、`SBUF`、波特率设置、`TI` 标志 | ⬜ |
| 09 | 看门狗 | 启动看门狗并喂狗，模拟程序卡死复位 | `WDT_CONTR`、喂狗、超时复位 | ⬜ |
| 10 | 内部 Flash 读写 | 掉电保存 LED 状态，上电自动恢复 | IAP/EEPROM、扇区擦除、字节读写 | ⬜ |

## 使用说明

1. **任务顺序**：任务 01 → 10 由浅入深，请勿跳号；前面的实验是后面实验的基础。
2. **例程位置**：每个任务对应的空工程模板在 `labs/` 目录下，参考答案在 `product/` 目录下，目录名与上表「任务名称」对应（如 `01-led-flow`）。
3. **动手要求**：先自己尝试写出代码，遇到困难再参考例程；不要直接复制答案。
4. **硬件准备**：实验基于 51 核心板，常用资源如下——

| 资源 | 引脚 |
| --- | --- |
| LED1 ~ LED4 | `P2.4` ~ `P2.7` |
| KEY1 ~ KEY3 | `P3.2` ~ `P3.4` |
| 蜂鸣器 BEEP | `P1.0` |
| 数码管段选 / 位选 | `P0` / `P2.3` ~ `P2.0` |
| 串口 TXD / RXD | `P3.1` / `P3.0` |

## 完成后

完成全部 10 项任务后，请完成大作业（见 `final-project.md`）——基于 51 单片机的串口电子钟，并制作汇报 PPT。
