# 51 单片机入门

初阶第二站。学习路径：先打板焊接 51 核心板，再用基础例程测试板子，然后在 Keil 上学习外设编程，最后完成大作业并做 PPT 汇报。

## 学习路径

1. PCB 打板与焊接 51 核心板（见 `circuit-design/`）。
2. 用基础例程测试板子，验证焊接与外设是否正常。
3. 在 Keil 上学习写代码（对应 `courseware/` 12 章 PPT）。
4. 完成大作业 + PPT 汇报。
