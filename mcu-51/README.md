# 51 单片机入门

初阶第二站。学习路径：先完成 PCB 打板与 51 核心板焊接，再用基础例程测试板子，随后在 Keil 上学习外设编程，最后完成大作业并做 PPT 汇报。

## 学习路径

1. PCB 打板（见 `circuit-design/`）。
2. 焊接 51 核心板。
3. 用基础例程测试板子（见 `solutions` 分支，验证焊接是否正确、各外设是否工作）。
4. 在 Keil 上学习写代码（对应 `courseware/` 12 章 PPT）。
5. 完成大作业 + PPT 汇报。

## 学员要完成

- 完成每章后面的任务（对应 `courseware/` 12 章 PPT）。
- 完成大作业（见 `assignments/`）。
- 完成 PPT 汇报。
