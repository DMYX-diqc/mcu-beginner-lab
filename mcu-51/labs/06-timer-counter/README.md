# 06. 定时器/计数器实验

> 目录：`06-timer-counter`

## 实验目的

通过本实验掌握 51 单片机的**定时器/计数器**：

1. 理解定时器/计数器的两种工作方式（**定时** 与 **计数**）；
2. 掌握定时器模式寄存器 `TMOD` 与初值 `TH0`/`TL0` 的配置；
3. 掌握定时器/计数器中断的使用；
4. 理解定时初值的计算方法（如定时 1ms）。

## 实验内容

工程包含两个子实验：

| 子实验 | 目录 | 说明 |
| --- | --- | --- |
| 定时器 | `timer/` | 定时器 0 定时 1ms，累计 1000 次（1s）翻转一次 LED |
| 计数器 | `counter/` | 计数器 0 计数 3 个脉冲翻转一次 LED |

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 定时/计数 | `TMOD` 模式配置（定时 `0x01` / 计数 `0x05`） |
| 初值装载 | `TH0` / `TL0` |
| 定时器中断 | `ET0`、`EA`、`interrupt 1` |
| 计数分频 | 累计 1000 次 = 1s |

## 硬件资源

- 定时器/计数器 0（T0）。
- LED1 接 `P2.4`。
- 计数器模式时，计数脉冲从 T0 引脚（`P3.4`）输入。

## 编译与烧录

1. 用 Keil C51 打开 `timer/` 或 `counter/` 下的 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 定时器实验观察 LED 周期闪烁；计数器实验在 T0 引脚输入脉冲观察 LED。

## 预期现象

- 定时器：LED1 每 1 秒翻转一次（约 0.5Hz 闪烁）。
- 计数器：T0 引脚每输入 3 个脉冲，LED1 翻转一次。
