# 02. 独立按键实验

> 目录：`02-independent-key`

## 实验目的

通过本实验掌握 51 单片机的 **GPIO 输入**与**按键消抖**：

1. 掌握 I/O 口作为**输入**读取引脚电平；
2. 理解按键的**机械抖动**现象；
3. 掌握**软件消抖**的方法（延时 + 二次确认）；
4. 学会按键控制 LED 的典型写法。

## 实验内容

按下核心板上的独立按键，控制对应 LED 亮灭翻转：KEY1 控制 LED1，KEY2 控制 LED2，KEY3 控制 LED3。

按键检测流程：

1. 第一次检测到按键按下（低电平）；
2. 延时约 50ms，跳过抖动；
3. 再次检测按键仍为按下，才确认有效；
4. 翻转对应 LED 状态，并等待按键松开。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| GPIO 输入 | 读取 `P3` 引脚电平 |
| 按键消抖 | 延时 + 二次确认 |
| 位定义 | `sbit KEY1 = P3^2;` |
| 状态取反 | `LED1 = ~LED1;` |

## 硬件资源

- KEY1 ~ KEY3 接 `P3.2` ~ `P3.4`（按下为低电平）。
- LED1 ~ LED3 接 `P2.4` ~ `P2.6`（低电平点亮）。

## 编译与烧录

1. 用 Keil C51 打开 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 按下按键，观察 LED 变化。

## 预期现象

每按一次按键，对应 LED 的亮灭状态翻转一次。

## 思考与拓展

1. 为什么需要消抖？如果去掉消抖会发生什么现象？
2. `while(0 == KEY1);` 这一句的作用是什么？
