# 04. 数码管实验

> 目录：`04-seg-display`

## 实验目的

通过本实验掌握 **数码管显示**与**动态扫描**：

1. 理解数码管的**段码**（字形编码）原理；
2. 掌握用**数组**存放 0~9 的段码表；
3. 掌握多位数码管的**动态扫描**显示方法；
4. 理解「位选」与「段选」的区别。

## 实验内容

在 4 位数码管上显示数字“1234”。通过快速轮流点亮每一位数码管，利用人眼视觉暂留实现稳定显示。

- 用 `P0` 输出段码（字形）；
- 用 `P2.0` ~ `P2.3` 控制位选（选择点亮哪一位）。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 段码 | 数码管字形编码表 `arrNumber[]` |
| 动态扫描 | 逐位点亮 + 短暂延时 |
| 数组 | `const unsigned char arrNumber[]` |
| 位选/段选 | 位选 `SegmentG1~G4`、段选 `P0` |

## 硬件资源

- 段选（字形数据）：`P0` 口。
- 位选（选择数码管）：`P2.0` ~ `P2.3` 对应第 4 ~ 第 1 位。

## 编译与烧录

1. 用 Keil C51 打开 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 上电后观察数码管。

## 预期现象

4 位数码管稳定显示数字“1234”。

## 思考与拓展

1. 动态扫描为什么要逐位快速切换？如果延时太长会怎样？
2. 如何把数码管显示的数字改成“5678”？改哪里？
