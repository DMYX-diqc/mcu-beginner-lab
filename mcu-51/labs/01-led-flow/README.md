# 01. LED 流水灯实验

> 目录：`01-led-flow`

## 实验目的

通过本实验掌握 51 单片机最基础的 **GPIO 输出控制**，这是学习单片机「点灯」的第一步：

1. 理解 51 单片机 I/O 口的**输出**特性；
2. 掌握用 `sbit` 对单个引脚进行**位控制**；
3. 掌握对整个端口（如 `P2`）进行**总线控制**；
4. 学会编写**软件延时函数**，实现 LED 的流动点亮。

## 实验内容

控制核心板上的 4 个 LED 依次点亮，形成“流水灯”效果。工程包含两种实现方式：

| 子实验 | 目录 | 说明 |
| --- | --- | --- |
| 总线控制 | `bus-control/` | 直接操作整个 `P2` 端口，用移位实现流水 |
| 按位控制 | `bit-control/` | 用 `sbit` 定义每个 LED，逐个点亮/熄灭 |

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| GPIO 输出 | `P2` 端口输出高低电平 |
| 位定义 | `sbit LED1 = P2^4;` |
| 延时函数 | 循环实现的软件延时 `DelayNms` |
| 移位运算 | `P2 = P2 << 1` |

## 硬件资源

- LED1 ~ LED4 接 `P2.4` ~ `P2.7`（按位控制）；总线控制使用整个 `P2` 口。
- 低电平点亮 LED。

## 编译与烧录

1. 用 Keil C51 打开 `bus-control/` 或 `bit-control/` 下的 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex`；
3. 用 STC 烧录软件将 `.hex` 烧写到核心板；
4. 上电或复位后观察 LED。

## 预期现象

4 个 LED 依次点亮并循环，形成流水灯效果（每个 LED 点亮约 500ms）。

## 思考与拓展

1. 「总线控制」和「按位控制」各有什么优缺点？
2. 如果把延时时间改短，流水灯会有什么变化？延时是怎么影响速度的？
