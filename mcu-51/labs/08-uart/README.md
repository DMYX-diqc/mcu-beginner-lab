# 08. 串口通信实验

> 目录：`08-uart`

## 实验目的

通过本实验掌握 51 单片机的 **UART 串口通信**：

1. 理解串口通信的基本概念（波特率、收发）；
2. 掌握串口工作方式与波特率的配置；
3. 掌握通过 `SBUF` 发送数据的流程；
4. 了解发送完成标志 `TI` 的使用。

## 实验内容

配置串口为模式 1，波特率 4800，循环向串口发送字符串 `123456789`。用串口助手在电脑上接收并显示。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 串口配置 | `SCON`（模式 1）、`TMOD`（定时器 1 模式 2） |
| 波特率 | `PCON`、`TL1` 设置波特率 4800 |
| 发送 | `SBUF = 数据`，等待 `TI` 置位 |
| 串口中断 | `ES`、`interrupt 4` |

## 硬件资源

- 串口 TXD 接 `P3.1`，RXD 接 `P3.0`。
- 通过 USB 转串口连接电脑，波特率 4800。

## 编译与烧录

1. 用 Keil C51 打开 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 打开串口助手，设置波特率 4800，观察接收到的数据。

## 预期现象

串口助手不断收到字符串 `123456789`。

## 思考与拓展

1. 波特率 4800 是怎么通过 `TL1 = 0xF3` 得到的？
2. 发送数据前为什么要 `while(!TI);` 等待？`TI` 由谁清零？
