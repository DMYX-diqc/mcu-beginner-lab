# 05. 外部中断实验

> 目录：`05-external-interrupt`

## 实验目的

通过本实验掌握 51 单片机的**外部中断**：

1. 理解中断的基本概念（主程序被打断去执行中断服务函数）；
2. 掌握外部中断 0（INT0）和外部中断 1（INT1）的配置；
3. 掌握**中断服务函数**的写法（`interrupt 0` / `interrupt 2`）；
4. 理解**触发方式**（下降沿触发）的设置。

## 实验内容

配置外部中断 0 和外部中断 1 为下降沿触发。当对应中断引脚出现下降沿时，进入中断服务函数，翻转对应的 LED。

- 外部中断 0 → 翻转 LED1；
- 外部中断 1 → 翻转 LED2。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 外部中断 | INT0 / INT1 的配置 |
| 中断控制寄存器 | `IT0`、`EX0`、`IT1`、`EX1`、`EA` |
| 中断服务函数 | `void X() interrupt 0` |
| 触发方式 | 下降沿触发 |

## 硬件资源

- 外部中断 0（INT0）接 `P3.2`，外部中断 1（INT1）接 `P3.3`。
- LED1 接 `P2.4`，LED2 接 `P2.5`。

## 编译与烧录

1. 用 Keil C51 打开 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 在 INT0 / INT1 引脚触发下降沿（如接按键），观察 LED。

## 预期现象

每触发一次外部中断，对应 LED 的状态翻转一次。

## 思考与拓展

1. `IT0 = 1` 表示什么触发方式？改成 `IT0 = 0` 又是什么？
2. 中断服务函数里的 `interrupt 0` 和 `interrupt 2` 分别对应哪个中断？
