# 07. PWM 与呼吸灯实验

> 目录：`07-pwm-breathing`

## 实验目的

通过本实验掌握 **PWM（脉宽调制）** 与**呼吸灯**的实现：

1. 理解 PWM 的基本概念（**周期** 与 **占空比**）；
2. 掌握用定时器生成 PWM 的方法；
3. 掌握定时器**模式 2（8 位自动重装）**的用法；
4. 理解通过改变占空比实现 LED 亮度渐变（呼吸灯）。

## 实验内容

用定时器 0 产生约 100us 的中断周期，在中断服务函数中：

1. 用一个计数器控制 PWM 周期（10ms）；
2. 用另一个计数器周期性地**递增/递减占空比**（20ms 调节一次）；
3. 根据占空比控制 LED 的亮灭，实现「由暗到亮、由亮到暗」的呼吸效果。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| PWM | 周期与占空比 |
| 定时器模式 2 | 8 位自动重装（`TMOD = 0x02`） |
| 占空比调节 | 递增/递减实现呼吸 |
| 静态变量 | `static` 计数器在中断中保持 |

## 硬件资源

- 定时器 0。
- LED1 接 `P2.4`（低电平点亮）。

## 编译与烧录

1. 用 Keil C51 打开 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 上电后观察 LED 亮度变化。

## 预期现象

LED1 的亮度缓慢地由暗变亮、再由亮变暗，循环往复，形成“呼吸”效果。

## 思考与拓展

1. PWM 的占空比和 LED 亮度是什么关系？
2. 定时器模式 2 和模式 1 有什么区别？为什么这里用模式 2？
