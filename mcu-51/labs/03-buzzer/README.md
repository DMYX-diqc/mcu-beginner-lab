# 03. 蜂鸣器实验

> 目录：`03-buzzer`

## 实验目的

通过本实验掌握 **GPIO 输出控制蜂鸣器**，并初步接触**宏定义**：

1. 掌握用 GPIO 输出驱动蜂鸣器（有源蜂鸣器）；
2. 掌握 `#define` 宏定义简化代码的用法；
3. 理解蜂鸣器「开 / 关」的控制方式。

## 实验内容

控制核心板上的蜂鸣器鸣叫 500ms 后停止。通过宏定义 `BEEP_ON` / `BEEP_OFF` 让代码更易读。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| GPIO 输出 | `P1^0` 控制蜂鸣器 |
| 宏定义 | `#define BEEP_ON BEEP = 0;` |
| 延时函数 | `DelayNms` 软件延时 |

## 硬件资源

- 蜂鸣器（BEEP）接 `P1.0`。
- 低电平（`BEEP = 0`）使蜂鸣器鸣叫。

## 编译与烧录

1. 用 Keil C51 打开 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 上电后观察（听）蜂鸣器。

## 预期现象

上电后蜂鸣器鸣叫约 500ms，然后停止。

## 思考与拓展

1. 使用宏定义 `BEEP_ON` / `BEEP_OFF` 相比直接写 `BEEP = 0` 有什么好处？
2. 有源蜂鸣器和无源蜂鸣器的控制方式有什么区别？
