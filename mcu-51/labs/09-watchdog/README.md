# 09. 看门狗实验

> 目录：`09-watchdog`

## 实验目的

通过本实验掌握 51 单片机的**看门狗（Watchdog）**：

1. 理解看门狗的作用——防止程序跑飞后系统死机；
2. 掌握看门狗控制寄存器 `WDT_CONTR` 的配置；
3. 掌握**喂狗**操作；
4. 理解看门狗超时后如何复位单片机。

## 实验内容

1. 启动看门狗，设置超时时间约 524.2ms；
2. 主循环中流水灯，并在循环中定期**喂狗**，保证程序正常运行时不会复位；
3. 通过外部中断 0 模拟一次“程序卡死”（延时 2s 不喂狗），使看门狗超时，观察单片机复位。

## 涉及知识点

| 知识点 | 说明 |
| --- | --- |
| 看门狗 | `sfr WDT_CONTR = 0xE1` |
| 超时设置 | `WDT_CONTR = 0x33` |
| 喂狗 | `WDT_CONTR |= 0x10` |
| 复位 | 超时未喂狗 → 复位 |

## 硬件资源

- 蜂鸣器 BEEP 接 `P1.0`；LED 接 `P2` 口。
- 外部中断 0（INT0）接 `P3.2`。

## 编译与烧录

1. 用 Keil C51 打开 `STC51KeilPrj.uvproj`；
2. 编译生成 `.hex` 并烧写到核心板；
3. 正常运行观察流水灯；触发 INT0 后观察复位现象。

## 预期现象

- 正常运行时：流水灯正常流动，程序不复位。
- 触发外部中断（模拟卡死）后：看门狗超时，单片机复位，流水灯重新开始。

## 思考与拓展

1. 看门狗为什么能防止程序“跑飞”？
2. 喂狗操作为什么不能放在中断里？放在主循环里有什么讲究？
