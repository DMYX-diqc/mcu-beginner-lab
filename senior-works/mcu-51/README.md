# 51 单片机学员作品

> 目录：`senior-works/mcu-51/`

这里收集老学员编写的、书上每章后面的作业代码（每个人写法不同，但都能跑通），按学员姓名分目录。

## 目录结构

```text
mcu-51/
└── <学员姓名>/<项目名>/     # 例如 zhangsan/01-led-flow/
```

## 提交规范

- 学员姓名目录建议用拼音或英文名（如 `zhangsan`）；
- 项目名尽量与 `mcu-51/labs/` 对应（如 `01-led-flow`、`03-buzzer`）；
- 放入完整可编译的工程（`.c`、`.h`、`.uvproj`），不要放编译产物；
- 建议附一个 `README.md` 说明作者、实验名称与实现思路。

## 相关目录

- 空工程模板：`mcu-51/labs/`
- 书上例题：`mcu-51/product/`
- 章节任务清单：`mcu-51/assignments/README.md`
