# 学员作品（Senior Works）

> 目录：`senior-works/`

这里收集老学员编写、经验证可以正常跑通的 51 单片机与 STM32 代码，供新学员参考学习。

## 目录结构

```text
senior-works/
├── mcu-51/                          # 51 单片机学员代码
│   └── <学员姓名>/<项目名>/          # 例如 zhangsan/01-led-flow/
└── stm32/                           # STM32 学员代码
    └── <学员姓名>/<项目名>/          # 例如 lisi/03.gpio-led-flow/
```

## 提交规范

- 每个学员一个以姓名命名的目录，建议用拼音或英文名（如 `zhangsan`），避免中文目录名带来兼容问题；
- 目录下按项目/实验分子目录，项目名尽量与 `labs/`（或 `product/`）对应，如 `01-led-flow`、`03.gpio-led-flow`；
- 只放「可以跑通」的完整工程（源码 `.c`/`.h` + 工程文件 `.uvproj`），不要放编译中间产物（`.obj`、`.hex`、`.lst` 等已由 `.gitignore` 忽略）；
- 每个项目建议附一个简短的 `README.md`，说明作者、实验名称、实现思路与运行效果。

## 与 labs / product 的区别

| 目录 | 内容 |
| --- | --- |
| `labs/` | 空工程模板，供学员自己动手写代码 |
| `product/` | 官方参考答案 |
| `senior-works/` | 老学员自己写的、已验证可跑通的作品 |

## 快速开始

新学员可先看 `labs/` 的空模板自己尝试；卡住时参考 `product/` 的官方答案，也可以参考 `senior-works/` 里学长学姐的实现思路。
