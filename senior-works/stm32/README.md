# STM32 学员作品

> 目录：`senior-works/stm32/`

这里收集老学员编写、可正常跑通的 STM32 代码，按学员姓名分目录。

## 目录结构

```text
stm32/
└── <学员姓名>/<项目名>/     # 例如 lisi/03.gpio-led-flow/
```

## 提交规范

- 学员姓名目录建议用拼音或英文名（如 `lisi`）；
- 项目名尽量与 `stm32/labs/` 对应（如 `03.gpio-led-flow`、`05.uart`）；
- 放入完整可编译的工程，不要放编译产物；
- 建议附一个 `README.md` 说明作者、实验名称与实现思路。

## 相关目录

- 空工程模板：`stm32/labs/`
- 官方参考答案：`stm32/product/`
- 章节任务清单：`stm32/assignments/README.md`
